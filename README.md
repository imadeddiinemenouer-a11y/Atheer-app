# ✦ أثير v12 — النواة الموحّدة (React)

مساعد عربي **local-first** — يعمل بلا خادم ولا إنترنت (افتراضياً)، بمعمارية React نظيفة.

## القدرات
- **محادثة هجينة**: ذاكرة BM25 + قواعد + مهارات Worker معزولة + نموذج GGUF محلي (wllama)
- **مصنّف نوايا** Naive Bayes يتعلم من 👍/👎
- **مكتبة** بضغط gzip وإخلاء تلقائي (ميزانية 2GB) + DOCX حقيقي + فهرس BM25
- **شبكة مفاهيم** (جوار/مسار) تُبنى تلقائياً
- **تقطير معرفة** من النموذج المحلي — نصوص دائمة لا أوزان
- **بصمة GGUF صادقة** (رأس الملف فقط)
- **مزامنة WebDAV** · **وضع خفي** · **سجل أخطاء + وضع آمن** · **ذاكرة حية** (انحلال أسّي)
- **حارس محلي صارم**: fetch مُغلَّف يرفض كل اتصال خارجي حتى إذن صريح

## التشغيل
```bash
npm ci
npm run dev      # تطوير
npm run build    # إنتاج → dist/
```

## النشر على GitHub
1. أنشئ مستودعاً وارفع الملفات (من تطبيق GitHub على الهاتف: Add file)
2. **Actions ← Build APK** → نزّل artifact `atheer-apk-vc*.zip` → ثبّت `app-debug.apk`
   - الحزمة ثابتة `com.atheer.app` وversionCode يزيد تلقائياً (run number) → **الترقية تحفظ بياناتك**
3. **Settings ← Pages ← GitHub Actions** → معاينة حية على الرابط

## ملاحظات
- ملفات GGUF (نماذج ~400MB) لا تُرفع للمستودع — استوردها داخل التطبيق من صفحة «النموذج»
- بعد كل تحديث للكود: commit → push → Actions يبني APK جديداً تلقائياً
- درس WebView cache: إن لم ترَ ميزة جديدة، أغلق التطبيق نهائياً وأعد فتحه
